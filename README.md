# 🎮 RPG Shinzo Maker

Собственный движок для создания тактических RPG в духе Shining Force.  
Включает **игровой движок на Ruby**, **редактор карт**, **редактор боевых сцен** и **главное окно-конструктор** на C + SDL2.

---

## 🧩 Компоненты

### 1. Игровой движок (Ruby + Raylib)

| Требование        | Значение                     |
|-------------------|------------------------------|
| Язык              | Ruby 4.0.2 (проверено, но подходят 3.2+) |
| Графика / Ввод    | Raylib 5.5+ (через гем `raylib-bindings 0.7.18`) |
| Платформа         | Windows / Linux / macOS      |
| Аудио             | Raylib Audio (MP3)           |
| Данные карт       | JSON                         |

**Возможности:**  
- Ходьба по карте с анимациями  
- Двухслойные карты (земля + декорации)  
- Система меню (Статус, Магия, Предметы, События)  
- Окно просмотра магии с иконками заклинаний  
- **Боевые сцены** с тактической расстановкой и анимациями  
- Динамические панели HP/MP с цветовыми слоями  

---

### 2. Редактор карт (C + SDL2)

| Требование        | Значение                     |
|-------------------|------------------------------|
| Язык              | C (GCC / MinGW)              |
| Графика           | SDL2 + SDL_image + SDL_ttf   |
| GUI               | Собственный (панели, диалоги)|
| Формат карт       | JSON (два слоя)              |
| Платформа         | Windows                      |

**Возможности:**  
- Два слоя тайлов (нижний — ландшафт, верхний — объекты)  
- Поворот / отражение тайлов  
- Назначение типов тайлов (проходимость)  
- Панорамирование и зум карты  
- Управление списком карт (создание, удаление, переименование, изменение размера)  
- Выбор фоновой музыки для карты  
- Сохранение путей к ресурсам в относительном виде  

---

### 3. Редактор боевых сцен (C + SDL2)

| Требование        | Значение                     |
|-------------------|------------------------------|
| Язык              | C (GCC / MinGW)              |
| Графика           | SDL2 + SDL_image + SDL_ttf   |
| GUI               | Собственный (панели, поля ввода) |
| Данные            | JSON (анимации, entries)     |
| Платформа         | Windows                      |

**Возможности:**  
- Предпросмотр боевого фона с правильным масштабированием (как в игре)  
- Загрузка анимаций союзников и врагов (`animation.json`)  
- Три фазы анимации: Idle, Attack, Defense  
- Редактирование смещений (`offset_x`, `offset_y`) и длительности кадров  
- Визуальное переключение кадров анимации  
- Чекбокс «Anim» для автоматического проигрывания  
- Функция **Rescan Frames** – автоматический подсчёт кадров по именам файлов (`idle_X.png`, `frame_attack_X.png`, `frame_def_X.png`, начиная с 1)  
- Сохранение изменённых анимаций обратно в JSON  
- Ручной ввод координат (клик по полю X/Y, набор цифр, Enter) с защитой от букв  
- Отображение земли (ground) под союзником  

---

### 4. Конструктор (главное окно, C + SDL2)

**Это центральный узел проекта.**  
Он собирает все редакторы в одном месте и позволяет запускать их по кнопкам.

| Требование        | Значение                     |
|-------------------|------------------------------|
| Язык              | C (GCC / MinGW)              |
| Графика           | SDL2 + SDL_image + SDL_ttf   |
| GUI               | Собственный (меню, тулбар)   |
| Платформа         | Windows                      |

**Запускаемые редакторы:**
- **Map Editor** – редактирование карт (`Maker/MapEditor.exe`)
- **Map Creator** – создание новых карт (`Maker/MapCreator.exe`)
- **Battle Editor** – редактор тактических битв (`Maker/BattleEditor.exe`)
- **Battle Scenes** – редактор боевых анимаций и сцен (`Maker/BattleScenes.exe`)
- **Text Editor** – редактор текстов (`Maker/text_editor.exe`)
- **Database** – база данных игры (`Maker/Database.exe`)

Окно конструктора адаптируется под размер экрана, кнопки имеют плавные анимации наведения.  
При запуске приложения консольное окно скрыто (используется флаг `-mwindows`).

---

## 🖱️ Управление зумом в редакторе карт

1. Наведи курсор на **область карты** (не на левую панель с тайлами).  
2. Зажми клавишу **Ctrl** (левый или правый).  
3. Крути колёсико мыши:  
   - **От себя** — приближение (зум увеличивается до 2.0×)  
   - **На себя** — отдаление (зум уменьшается до 0.5×)

Текущий масштаб отображается плавно, без рывков.

## 🔧 Установка и сборка

### Игровой движок (Ruby)

```bash
gem install raylib-bindings
ruby game.rb

Сборка в .exe
bash
gem install ocran -v 1.4.3

С окном консоли:

bash
ocran game.rb


Без консоли (оконное приложение):

bash
ocran game.rb --windows --output Shinzo.exe


📋 Зависимости
Ruby 3.2+ / 4.0.2

Raylib 5.5+ (с биндингом raylib-bindings 0.7.18)

GCC (MinGW для Windows)

SDL2, SDL2_image, SDL2_ttf

cJSON (включён в репозиторий)

ocran (для упаковки Ruby-приложений в .exe)
