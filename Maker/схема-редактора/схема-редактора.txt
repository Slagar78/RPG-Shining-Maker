📁 Формат JSON: Сохранение с табами (CJsonFormatter)

Пример data/maps/entries.json:
[{ "id": 0, "folder": "Granseal", "name": "Granseal", ... }]

Пример data/battles/entries.json:
[{ "folder": "battle00", "name": "Battle #0", "map_id": 1, "music": "...", ... }]

Пример события в events.json (обычное):
{ "type": "counter", "x": 5, "y": 10 }

Пример варпа в events.json (теперь по ID, а не по имени):
{ "type": "warp", "trigger_x": 3, "trigger_y": 3, "target_map_id": 0, "target_x": 55, "target_y": 3, "facing": 3 }

Пример врага в enemies.json:
{ "id": 0, "name": "Gyasa", "items": [{ "item_id": 5, "equipped": true }], "spells": [1, -1, -1, -1], "spell_levels": [2, 1, 1, 1] }

Пример start_inventory.json:
{ "start_inventory": [{ "actor_id": 0, "class_id": 0, "start_level": 1, "items": [{ "item_id": 5, "equipped": true }, { "item_id": -1, "equipped": false }] }] }

Пример shops.json:
{ "shops": [{ "id": 0, "name": "Granseal Weapons", "type": "weapon", "items": [5, 7, 6, 4] }] }

Пример global.json:
{ "start_map_id": 0, "start_x": 12, "start_y": 14, "gold": 50 }

Правила:
• Табы (\t), каждый элемент с новой строки.
• Вложенные массивы (tiles, collision, collision2) пишутся горизонтально.
• Игра на Ruby читает без ошибок.


📐 Правила, чтобы код не превратился в кашу

#   Правило                                        Как соблюдать
1   Один редактор — одна папка                     TilesetImporter в Editors/TilesetImporter/.
2   Partial-файлы для больших редакторов            MapEditor = 11, EventEditor = 7, Importer = 4, Database = Views/.
3   Core — общий для всех                           Модели и сервисы в Core/.
4   MainWindow знает только IEditor                 Никаких ссылок на конкретные классы.
5   Общение редакторов — через Core                 Импортер вызывает MapJsonService, EntriesService.
6   События для оболочки                            StatusChanged — MainWindow ловит.
7   Отдельный Canvas — отдельный класс              Свой *Canvas для кастомного рендера.
8   FullRedraw ≠ RedrawCanvas                       FullRedraw — смена карты, RedrawCanvas — UI.
9   subAreas — макс 10                              Индексы 0..9. Main и sub строго разделены.
10  Формат JSON — читаемый                          Свой StringBuilder с табами. Массивы горизонтально.
11  Безопасность имен                               При импорте RU->EN транслитерация.
12  Counter = невидимая логика                      Прилавок разрешает диалог сквозь себя (talk_through).
13  Базовая графика и Оверрайды                     Кружки (0-3) в блоксете, квадраты (5-8) на карте.
14  Изоляция графики (Playtest)                     Mesa (opengl32.dll) + llvmpipe для WGL.
15  Кинематографичный старт                         Splash ждет Opened, затем плавно исчезает.
16  DatabaseEditor = MVVM                           Binding, ObservableCollection, RelayCommand.
17  Два слоя коллизий                               L1 (collision), L2 (collision2). Оверлей показывает активный.
18  Единый источник истины                          BattleManager получает ссылки на @party и @start_inventory.
19  SpellLevels                                     У заклинания один ID и массив levels.
20  ActorBlocks                                     actors.json — плоский список, редактор разворачивает.
21  Конвертеры в Shared/Converters                  Все IValueConverter в Desktop/Shared/Converters.
22  Портреты относительным путем                    PortraitConverter + ProjectPaths.AssetsDir.
23  EnemyStats = Growth                             Статы с кривыми роста. EnemiesService подставляет значения.
24  Parallel Arrays (Enemies)                       spells + spell_levels. В редакторе — ObservableCollection.
25  ProwessCatalog                                  Общий статический каталог токенов.
26  Связь по ID (Items & Spells)                    В enemies, start_inventory, shops — ТОЛЬКО item_id (-1 = пусто).
27  Глобальные настройки по ID                      В global.json start_map_id (число) вместо строки. Игра ищет папку через entries.json.
28  Варпы по ID                                     В events.json target_map_id (число) вместо target_map. Игра ищет папку через entries.json.
29  Современный UI в MapEditor                      Использовать стили ModernComboBox для нижней панели (Map, Size, Tileset, Music).
30  Современные вкладки (VS Code style)             Переопределять TabItem Template в MainWindow.axaml (скругление сверху, синяя полоса).
31  Универсальный поиск карты в GameMap             GameMap.new принимает и строку (folder), и число (id). Сохраняет @map_id и @db_id.
