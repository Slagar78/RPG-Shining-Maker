  RPG-Shinzo Maker — редактор карт для движка RPG-Shining-Maker
════════════════════════════════════════════════════════════════════

  Порт C-редактора (SDL2) на C# + Avalonia.
  Написан в IDE JetBrains Rider.


────────────────────────────────────────────────────────────────────
  СТЕК
────────────────────────────────────────────────────────────────────

  Язык ............. C# 14
  Платформа ........ .NET 10
  UI-фреймворк ..... Avalonia 12.1.3
  IDE .............. JetBrains Rider 2025+


────────────────────────────────────────────────────────────────────
  ЧТО НУЖНО ПОСТАВИТЬ
────────────────────────────────────────────────────────────────────

  1. .NET 10 SDK
     https://dotnet.microsoft.com/download/dotnet/10.0
     Проверка: открой cmd и введи:
         dotnet --version
     Должно показать 10.x

  2. JetBrains Rider (рекомендуется)
     https://www.jetbrains.com/rider/download/
     Лицензия: выбери "Non-commercial use" — бесплатно на год.

     ИЛИ Visual Studio Community 2022 (альтернатива)
     https://visualstudio.microsoft.com/vs/community/
     При установке выбрать ".NET desktop development"

  3. Плагин AvaloniaRider (в Rider)
     File → Settings (Ctrl+Alt+S) → Plugins → Marketplace
     Введи: Avalonia
     Установи: AvaloniaRider (от Avalonia Team)
     Перезапусти Rider.

────────────────────────────────────────────────────────────────────
  ФОРМАТ ДАННЫХ
────────────────────────────────────────────────────────────────────

  Редактор читает и сохраняет те же файлы, что и движок на Ruby:

    data/maps/entries.json
        Список всех карт: folder, name, music, music_volume, areas

    data/maps/{folder}/layout.json
        Данные карты: width, height, tileset, tiles, rot, mirror_x/y,
        tiles2, rot2, mirror_x2/y2, collision

    data/maps/{folder}/areas.json
        Область карты (mainLayerStart / mainLayerEnd)

    data/tile_types/{tileset}.json
        Типы тайлов (passable/block/slow/under) для тайлсета

  Формат идентичен C-версии и читается движком на Ruby — 
  рисуешь в редакторе, сохраняешь, игра подхватывает.

  КАК ЗАПУСТИТЬ
────────────────────────────────────────────────────────────────────

  Из терминала (cmd / PowerShell):

      cd C:\SHINZO\RPG-Shining-Maker\Maker\src\RpgShinzoMaker.Desktop
      dotnet build
      dotnet run

  Из Rider:

      Открыть решение RpgShinzoMaker.sln
      Shift+F10  — запустить
      Ctrl+F9    — только собрать
