Поток данных: клик по карте
 [мышь клик]
    │
    ▼
MapCanvas.axaml.cs (Views/)
    │  событие TileClicked(tx, ty, tileId, isLeft)
    ▼
MapEditorView.Painting.cs → OnMapTileClicked()
    │
    ├─→ если Select Mode:    → Select.cs (CopySelectionToClipboard)
    ├─→ если Grid Mode:      → AssignTypeToMapTile() → MapCanvas.UpdateGridOverlay()
    ├─→ если просто рисование → PaintTile() → MapCanvas.RedrawTile()
    └─→ если Tile Editor:    → ApplyTransform() → TileEditor.RenderTileWithTransform()
	
Поток данных: SAVE

	[клик по кнопке 💾 SAVE]
    │
    ▼
MainWindow.axaml.cs → OnSaveClick()
    │  GetActiveEditor() → IEditor
    ▼
editor.Save()   (для MapEditor это → MapEditorView.Map.cs → SaveCurrentMap)
    │
    ├─→ MapJsonService.Save()      → data/maps/<map>/layout.json
    ├─→ TileTypesService.Save()    → data/tile_types/<tileset>.json
    ├─→ AreasService.Save()        → data/maps/<map>/areas.json
    └─→ EntriesService.Save()      → data/maps/entries.json

📐 Правила, чтобы код не превратился в кашу
#	Правило	Как соблюдать
1	Один редактор — одна папка	Хочешь BattleEditor → Editors/BattleEditor/. Не лезь в MapEditor/.
2	Partial-файлы для больших редакторов	MapEditorView — не один файл на 3000 строк, а 9 partial по 100–400 строк. Каждый — за свою область.
3	Core — общий для всех	Модели и сервисы в Core/. Любой редактор их использует.
4	MainWindow знает только IEditor	Никаких ссылок на конкретные классы редакторов. Только интерфейс.
5	Общение между редакторами — через Core	Не через прямые ссылки. BattleEditor захочет карту — вызовет MapJsonService.Load.
6	События для взаимодействия с оболочкой	Не пихать логику MainWindow в редактор. Редактор кидает событие — MainWindow его ловит.
