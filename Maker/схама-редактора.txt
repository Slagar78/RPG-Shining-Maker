Алгоритм импорта:
1. Загрузка PNG (размер кратен 48x48).
2. Нарезка на тайлы 48x48, поиск уникальных (через хэш-таблицу).
3. Сборка тайлсета 1536x1536 (сетка 32x32, полосами по 8 штук).
4. Отображение сеткой с рамками.
5. Кнопка "Save Tileset" (сохранить только PNG) или "Save as Map" (создать layout.json, areas.json, entries.json).


📁 Формат JSON: Сохранение с табами ★ ОБНОВЛЕНО

Мы отказались от WriteIndented и переписали сохранение вручную.
Теперь файлы сохраняются в точности как в C-программе (cJSON).

Пример entries.json:
[{
		"id":	0,
		"folder":	"Granseal",
		"name":	"Granseal",
		"music":	"assets/sounds/Track1.mp3",
		"music_volume":	0.8,
		"areas":	"data/maps/Granseal/areas.json"
	}, {
		"id":	1,
		"folder":	"map00"
	}]

Правила:
• Используются табы (\t) для отступов.
• Нет склеивания в одну строку.
• Каждый элемент с новой строки.
• Игра на Ruby читает это без ошибок.

📐 Правила, чтобы код не превратился в кашу (дополнено)

#   Правило                                        Как соблюдать
1   Один редактор — одна папка                     TilesetImporter лежит в Editors/TilesetImporter/.
2   Partial-файлы для больших редакторов            MapEditor = 11 файлов, EventEditor = 7 файлов,
                                                     TilesetImporter = 4 файла. Каждый — за свою область.
3   Core — общий для всех                           Модели и сервисы в Core/. Любой редактор их использует.
4   MainWindow знает только IEditor                  Никаких ссылок на конкретные классы редакторов.
5   Общение между редакторами — через Core          Импортер вызывает MapJsonService.Save и EntriesService.Save.
6   События для взаимодействия с оболочкой          Редактор кидает StatusChanged — MainWindow его ловит.
7   Отдельный Canvas — отдельный класс              Если редактор хочет свой рендер — создаёт свой *Canvas.
8   FullRedraw ≠ RedrawCanvas                       FullRedraw — при смене карты, RedrawCanvas — на изменения UI.
9   subAreas — макс 10                               Индексы 0..9. Main всегда main, sub — всегда sub.
10  Формат JSON — читаемый                          ★ ОБНОВЛЕНО: Свой StringBuilder-форматтер с табами (\t).
11  Безопасность имен                               ★ НОВОЕ: При импорте имена проходят транслитерацию (RU->EN).
