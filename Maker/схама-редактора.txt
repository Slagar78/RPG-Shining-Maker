	📐 Правила, чтобы код не превратился в кашу
#	Правило	Как соблюдать
1	Один редактор — одна папка	Хочешь BattleEditor → Editors/BattleEditor/. Не лезь в MapEditor/ или EventEditor/.
2	Partial-файлы для больших редакторов	MapEditorView = 11 partial по 100–400 строк. EventEditorView = 7 partial. Каждый — за свою область.
3	Core — общий для всех	Модели и сервисы в Core/. Любой редактор их использует.
4	MainWindow знает только IEditor	Никаких ссылок на конкретные классы редакторов. Только интерфейс.
5	Общение между редакторами — через Core	Не через прямые ссылки. EventEditor захочет карту — вызовет MapJsonService.Load.
6	События для взаимодействия с оболочкой	Не пихать логику MainWindow в редактор. Редактор кидает StatusChanged — MainWindow его ловит.
7	Отдельный Canvas — отдельный класс	Если редактор хочет свой рендер — создаёт свой *Canvas.axaml. Не модифицирует чужой.
8	FullRedraw ≠ RedrawCanvas	FullRedraw — только при смене карты (пересоздание 8192 Image). RedrawCanvas — на каждое изменение UI (только оверлей). Это критично для скорости.
